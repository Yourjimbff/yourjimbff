# Photos for /join

Drop the files in here using these exact names. The page picks them up with no
code change — until a file exists, its frame shows the filename instead of a
broken image, so it's obvious what's still missing.

    yusuf-before.jpg        yusuf-after.jpg
    client-1-before.jpg     client-1-after.jpg
    client-2-before.jpg     client-2-after.jpg
    client-3-before.jpg     client-3-after.jpg
    client-4-before.jpg     client-4-after.jpg
    client-5-before.jpg     client-5-after.jpg

Portrait, roughly 3:4. The frames crop to fill, so anything squarer loses the top
and bottom. Same distance and framing between a before and its after or the pair
doesn't read as a comparison.

Four clients is fine — delete the fifth `.client` block in `../index.html`.

Client photos need the client's permission before they go up.
